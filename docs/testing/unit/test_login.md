# ログイン機能 単体テスト仕様書

## 1. テスト概要

- 対象モジュール：`login/views.py`
- テストコード：`tests/unit/test_login.py`
- テストフレームワーク：pytest
- テスト方式：単体テスト（DBアクセスはモック化）
- 目的：ログイン時の入力検証、DB照合処理、画面遷移が正しく動作することを確認する。

## 2. テストケース一覧

| ID | テスト関数 | テスト内容 | 期待結果 |
|---|---|---|---|
| REG-001 | test_login_get | GETでログイン画面にアクセス | ステータス200 | 
| REG-002 | test_login_empty_username | ユーザー名が空 | 「名前を入力してください」 | 
| REG-003 | test_login_empty_password | パスワードが空 | 「パスワードを入力してください」 | 
| REG-004 | test_login_wrong_password | パスワードが間違っている | 「パスワードが違います」 | 
| REG-005 | test_login_success | 正しいユーザー名・パスワード | login_user() が呼ばれ、リダイレクト | 
| REG-006 | test_login_unknown_user | 存在しないユーザー名 | ログインされず、ログイン画面を表示 | 

## 3. テストケース詳細

### REG-001：GETでログイン画面にアクセス

**対象関数：** `test_login_get(client)`

**目的：**

/loginルートにGETメソッドでアクセスした際に、正しくログイン画面が表示されるかを確認する

**前提条件：**

- Flaskテストクライアントが利用可能

**期待結果：**

1. HTTPステータスコードが200である

### REG-002：ユーザー名が空

**対象関数：** `test_login_empty_username(client)`

**目的：**

usernameフィールドが空の状態でPOSTされた時に、エラーメッセージ「名前を入力してください」が正しく表示され、/loginルートにリダイレクトされるかを検証する

**前提条件：**

- Flaskテストクライアントが利用可能
- SQLAlchemyのsessionをモック化
- 実際のデータベースには接続しない

**入力データ：**

| 項目 | 値 |
|---|---|
| username |  |
| password | password123 |

**期待結果：**

1. HTTPステータスコードが302である。
2. リダイレクト先が `/login/` である。

### REG-003：パスワードが空

**対象関数：** `test_login_empty_password(client)`

**目的：**

passwordフィールドが空の状態でPOSTされた時に、エラーメッセージ「パスワードを入力してください」が正しく表示され、/loginルートにリダイレクトされるかを検証する

**前提条件：**

- Flaskテストクライアントが利用可能
- SQLAlchemyのsessionをモック化
- 実際のデータベースには接続しない

**入力データ：**

| 項目 | 値 |
|---|---|
| username | testuser |
| password |  |

**期待結果：**

1. HTTPステータスコードが302である。
2. リダイレクト先が `/login/` である。


### REG-004：パスワードが間違っている

**対象関数：** `test_login_wrong_password(client)`

**目的：**

passwordフィールドに入力されたパスワードのハッシュ値とデータベースに登録された該当ユーザーのパスワードのハッシュ値を比較し、一致しない場合、エラーメッセージ「パスワードが違います」が正しく表示され、/loginルートにリダイレクトされるかを検証する

**前提条件：**

- Flaskテストクライアントが利用可能
- SQLAlchemyのsessionをモック化
- 実際のデータベースには接続しない

**入力データ：**

| 項目 | 値 |
|---|---|
| username | testuser |
| password | wrong_password |

**期待結果：**

1. HTTPステータスコードが302である。
2. リダイレクト先が `/login/` である。

### REG-005：正しいユーザー名・パスワード

**対象関数：** `test_login_success(client)`

**目的：**

usernameにデータベースに登録済みのユーザー名が入力され、かつ、passwordフィールドに入力されたパスワードのハッシュ値とデータベースに登録された該当ユーザーのパスワードのハッシュ値を比較して一致した場合、/topルートにリダイレクトされるかを検証する

**前提条件：**

- Flaskテストクライアントが利用可能
- SQLAlchemyのsessionをモック化
- 実際のデータベースには接続しない

**入力データ：**

| 項目 | 値 |
|---|---|
| username | testuser |
| password | password123 |

**期待結果：**

1. HTTPステータスコードが200である。
2. リダイレクト先が `/top/` である。

### REG-006：存在しないユーザー名

**対象関数：** `test_login_unknown_user(client)`

**目的：**

usernameにデータベースに登録されていないユーザー名が入力された場合、パスワードの値に関わらずログイン処理は行わず、ログイン画面を表示

**前提条件：**

- Flaskテストクライアントが利用可能
- SQLAlchemyのsessionをモック化
- 実際のデータベースには接続しない

**入力データ：**

| 項目 | 値 |
|---|---|
| username | unknown |
| password | password123 |

**期待結果：**

1. HTTPステータスコードが302である。
2. リダイレクト先が `/login/` である。

## 4. テスト実行方法

```bash
python -m pytest tests/unit/test_login.py -v
```

## 5. 合格基準

- 定義された6件のテストがすべてPASSEDになること。
- テスト実行中に予期しない例外が発生しないこと。
- テスト実行によって本番データベースが変更されないこと。
