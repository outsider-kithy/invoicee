# トップページ 単体テスト仕様書

## 1. テスト概要

- 対象モジュール：`top/views.py`
- テストコード：`tests/unit/test_top.py`
- テストフレームワーク：pytest
- テスト方式：単体テスト（DBアクセスとテンプレート描画をモック化）
- 目的：案件一覧取得、金額集計、画面へのデータ受け渡し、未認証アクセス制御を検証する。

## 2. テストケース一覧

| ID | テスト関数 | テスト内容 | 期待結果 |
|---|---|---|---|
| TOP-001 | test_top_get | トップページにアクセス | HTTP 200 |
| TOP-002 | test_top_empty_jobs | 案件が0件 | 空のjob_list、合計0円 |
| TOP-003 | test_top_single_job | 案件が1件 | 案件の金額が正しく設定される |
| TOP-004 | test_top_multiple_jobs | 複数案件の金額集計 | 案件ごとの金額と合計金額が正しい |
| TOP-005 | test_top_zero_price | 案件の金額が0円 | 0円として正常に処理される |
| TOP-006 | test_top_login_required | 未認証アクセス | ログイン画面へリダイレクト、DBアクセスなし |

## 3. テストケース詳細

### TOP-004：複数案件の金額集計

**対象関数：** `test_top_multiple_jobs(client)`

**目的：**

複数案件が存在する場合に、それぞれの金額が正しく取得され、合計金額が計算されることを確認する。

**入力データ：**

| 案件ID | 金額 |
|---|---:|
| 1 | 10,000円 |
| 2 | 20,000円 |

**期待結果：**

1. HTTPステータスコードが200である。
2. `job_list` に2件の案件が格納される。
3. 各案件の `current_price` が正しい。
4. `monthly_total_price` が30,000円である。

**検証範囲外：**

- 実際のSQL JOINの動作
- PostgreSQLでのSUM集計
- HTMLテンプレートの描画内容

これらは結合テストで検証する。

## 4. テスト実行方法

```bash
python -m pytest tests/unit/test_top.py -v
```

## 5. 合格基準

- 6件のテストがすべてPASSEDになること。
- 案件ごとの金額と合計金額が正しく計算されること。
- 未認証ユーザーからのアクセスが制限されること。
