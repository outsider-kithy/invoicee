# ログアウト機能 単体テスト仕様書

## 1. テスト概要

- 対象モジュール：`logout/views.py`
- テストコード：`tests/unit/test_logout.py`
- テストフレームワーク：pytest
- テスト方式：単体テスト（Flask-Loginの認証状態をモック化）
- 目的：ログアウト処理、画面遷移、未認証アクセス制御が正しく動作することを確認する。

## 2. テストケース一覧

| ID | テスト関数 | テスト内容 | 期待結果 |
|---|---|---|---|
| OUT-001 | test_logout_success | ログイン済みユーザーのログアウト | HTTP 302、logout_user()実行 |
| OUT-002 | test_logout_redirect | ログアウト後のリダイレクト | `/login` にリダイレクト |
| OUT-003 | test_logout_required | 未ログインユーザーのアクセス | ログイン画面へリダイレクト、logout_user()未実行 |
| OUT-004 | test_logout_user_called_once | logout_user()の実行回数 | 1回だけ実行される |

## 3. テストケース詳細

### OUT-001：ログアウト成功

**対象関数：** `test_logout_success(client)`

**目的：**

ログイン済みユーザーがログアウトページへアクセスした場合、ログアウト処理が正常に実行されることを確認する。

**前提条件：**

- Flaskテストクライアントが利用可能
- Flask-Loginの認証状態をモック化
- 認証済みユーザーとしてアクセスする

**期待結果：**

1. HTTPステータスコードが302である。
2. `logout_user()` が1回実行される。

### OUT-003：未ログインユーザーのアクセス

**対象関数：** `test_logout_required(client)`

**目的：**

未ログインユーザーがログアウトページへアクセスした場合、`@login_required` によってログアウト処理が実行されないことを確認する。

**期待結果：**

1. HTTPステータスコードが302である。
2. ログインページへリダイレクトされる。
3. `logout_user()` は実行されない。

## 4. テスト実行方法

```bash
python -m pytest tests/unit/test_logout.py -v
```

## 5. 合格基準

- 定義された4件のテストがすべてPASSEDになること。
- 未ログインユーザーによるログアウト処理が実行されないこと。
- ログアウト後の画面遷移が仕様どおりであること。
